CursAnimation

Library custom cursor dan animasi rebuild on scroll tanpa dependency. Kursor, swarm, trail, partikel, magnetik, klik, reveal, dan efek membangun elemen seperti di Swarm.

Instalasi

Ada dua cara: CDN untuk HTML statis, atau package untuk project dengan bundler. Stylesheet wajib dimuat — tanpa CSS, overlay tidak akan tampil.

CDN (tanpa build)

Muat CSS di <head> dan JavaScript sebelum konfigurasi. Ganti versi secara eksplisit agar stabil.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rexxzyid/cursanimation@1.5.4/dist/cursanimation.min.css">
<script src="https://cdn.jsdelivr.net/gh/rexxzyid/cursanimation@1.5.4/dist/cursanimation.min.js"></script>

Package (GitHub Packages)

Tambahkan registry dan token ke .npmrc, lalu install.

@rexxzyid:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${NODE_AUTH_TOKEN}
npm install @rexxzyid/cursanimation
import CursAnimation from "@rexxzyid/cursanimation";
import "@rexxzyid/cursanimation/css";

CursAnimation.init({ cursor: "ring" });

Package ada di GitHub Packages, jadi instalasi butuh token dengan scope read:packages. Untuk situs statis, CDN lebih sederhana.

Mulai cepat

Inisialisasi kursor sekali, lalu tambahkan rebuild untuk elemen yang ingin dianimasikan saat masuk viewport.

CursAnimation.init({
  cursor: "ring",
  color: "#f3f0e8",
  color2: "#ffd84d",
  size: 32,
  movement: "elastic",
  magnetic: { enabled: true, radius: 90, strength: 0.35 },
  hoverEffects: true
});

CursAnimation.rebuild({
  selector: ".reveal",
  revealClass: "visible",
  typeText: true,
  pen: true
});

Pasangkan dengan CSS berikut supaya elemen tersembunyi sampai proses build selesai.

.reveal {
  opacity: 0;
}

.reveal.visible {
  opacity: 1;
}

Efek

Efek bisa diaktifkan dengan true atau objek untuk mengatur detailnya. trail, particles, clickEffects, magnetic, dan swarm menerima boolean atau objek.

Swarm

Sekumpulan kursor berwarna yang mengorbit, berputar, dan menghindari pointer.

CursAnimation.init({
  cursor: "ring",
  swarm: {
    enabled: true,
    count: 12,
    radius: 150,
    size: 26,
    speed: 1,
    avoid: 52,
    hideCursor: true
  }
});

size26Ukuran tiap kursor (10–64).
speed1Kecepatan animasi (0.2–3).

hideCursortrueSembunyikan kursor tunggal saat swarm aktif.

Trail & partikel

trail.style: dots, gradient, neon. particles.shape: dot, sparkle, mixed.

Reveal

Animasi masuk sederhana berbasis IntersectionObserver. Berbeda dari rebuild: teks tidak dikosongkan, hanya elemen yang ditransformasikan.

CursAnimation.reveal({
  selector: "[data-ca-reveal]",
  once: false,
  threshold: 0.12,
  animation: "fade-up",
  duration: 700,
  stagger: 70,
  distance: 28
});

Rebuild on scroll

Efek utama ala Swarm. Saat elemen masuk viewport, library menggambar kotak, mengetik teks per karakter, menelusuri media dengan pen, lalu membersihkan overlay. Jika once: false, elemen dibangun ulang setiap kali kembali terlihat.

1Box

Kursor menggambar outline dan label ukuran.

2Type

Teks diisi karakter demi karakter dengan caret.

3Pen

Garis menelusuri media, lalu media di-reveal.

4Exit

Kursor keluar, overlay dibersihkan, class reveal ditambahkan.

HTML & CSS wajib

<section class="reveal">
  <h2>Judul</h2>
  <p>Deskripsi</p>
</section>
.reveal {
  opacity: 0;
}

.reveal.visible {
  opacity: 1;
}
CursAnimation.rebuild({
  selector: ".reveal",
  revealClass: "visible",
  threshold: 0.14,
  duration: 440,
  agents: 2,
  color: "auto",
  autoDark: "#111111",
  autoLight: "#f3f0e8",
  typeText: true,
  typeSelector: "h1,h2,h3,p,li,blockquote",
  charDelay: 9,
  maxTypeDuration: 980,
  pen: true,
  stagger: 60,
  maxConcurrent: 2
});

Catatan implementasi

  • Replay: dengan once: false, class reveal dilepas saat elemen keluar viewport, lalu build diulang ketika masuk lagi.
  • Teks: teks di dalam typeSelector dikosongkan saat build dimulai. Jangan menaruh elemen interaktif di dalam teks yang diketik.
  • Media: img, svg, video, canvas, picture, dan iframe ikut tertutup sampai fase pen selesai.
  • Konten dinamis: panggil refresh() setelah menambah elemen baru.
  • Performa: gunakan agents: 1, maxConcurrent: 1, typeSelector: "h1,h2", dan duration lebih pendek di mobile.

Performa

Efek kursor berjalan selama pointer bergerak dan bisa membebani perangkat kelas bawah. Rekomendasi:

  • Aktifkan kursor hanya pada perangkat dengan mouse: matchMedia("(pointer: fine)").matches.
  • Kurangi swarm.count (8–12), matikan trail, dan kecilkan clickEffects.count.
  • Di mobile, pakai rebuild ringan: agents: 1, typeSelector: "h1,h2", maxConcurrent: 1.
  • Hindari backdrop-filter, mix-blend-mode, dan layer fixed full-screen di halaman yang berat.
  • Muat script dengan defer agar tidak memblokir render.
  • respectReducedMotion: true otomatis mematikan efek berat bagi pengguna yang memintanya.
const finePointer = matchMedia("(pointer: fine)").matches;

if (finePointer) {
  CursAnimation.init({ cursor: "ring", swarm: { enabled: true, count: 10 } });
}

CursAnimation.rebuild({
  selector: ".reveal",
  agents: 1,
  typeSelector: "h1,h2",
  maxConcurrent: 1
});

Troubleshooting

Kursor tidak muncul

Pastikan CSS sudah dimuat dan init() dipanggil. Cek Console untuk error opsi. Di perangkat sentuh, kursor memang disembunyikan.

Elemen tetap tidak terlihat setelah rebuild

Pastikan revealClass sama dengan CSS, misalnya revealClass: "visible" dan .reveal.visible { opacity: 1 }. Tanpa IntersectionObserver, elemen langsung ditampilkan.

Rebuild tidak mengulang

Gunakan once: false (default). Elemen harus benar-benar keluar viewport agar class reveal dilepas.

Garis overlay salah posisi saat scroll

Gunakan versi 1.5.3 ke atas — overlay sudah menempel ke dokumen, bukan viewport.

Gagal install dari GitHub Packages

Tambahkan .npmrc dan token dengan scope read:packages. Alternatif termudah: pakai CDN.

Kursor ganda

Pastikan hanya satu instance CursAnimation yang aktif. Panggil destroy() sebelum init ulang, atau gunakan setOptions().

Browser & lisensi

Menggunakan feature detection, bukan sniffing. Pointer Events dipakai bila tersedia; tanpa matchMedia efek tetap aktif; tanpa IntersectionObserver elemen langsung tampil. Overlay selalu pointer-events: none dan animasi berhenti saat tab tidak aktif.
